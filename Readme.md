# Mini Mario Platformer

This repository contains a standalone HTML canvas platformer. You can run it locally without any build tools.

## How to Run
1. From this directory, start a simple web server (any static server works). For example:
   ```bash
   python -m http.server 8000
   ```
2. Open the game in your browser at http://localhost:8000/index.html.
3. Use **←/→** to move and **W/↑/Space** to jump. Collect all the coins to win.

## Notes
- The game is self contained in `index.html`.
- To restart after winning or losing, press **Enter**.
